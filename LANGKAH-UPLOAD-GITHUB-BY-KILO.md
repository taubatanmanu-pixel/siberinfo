**LANGKAH-UPLOAD-GITHUB-BY-KILO.md**
1. BUKA GITHUB.COM -> LOGIN AKUN ANDA.
2. KLIK TOMBOL "+" DI ATAS KANAN -> PILIH "New repository".
3. ISI NAMA REPOSITORY: siberinfo -> PILIH "Public" -> CENTANG "Add a README file" (opsional) -> KLIK "Create repository".
4. SETELAH REPOSITORY DIBUAT, KLIK TOMBOL HIJAU "Upload files".
5. GUNAKAN TOMBOL "Add files" -> "Upload files" (atau drag and drop).
6. PILIH SEMUA FILE DARI FOLDER `C:\xampp\htdocs\WebDev\siberinfo` KECUALI FOLDER `api` DAN `uploads`.
    * File yang harus ada: index.html, admin.html, app.js, admin.js, style.css, style.min.css, tailwind.css, supabase-config.js, README.md, .gitignore.
7. KLIK "Commit changes".
**LANGKAH AKTIFKAN GIT-CAR-DEV**
1. KLIK TOMBOL "Settings" DI MENU REPOSITORY.
2. SCROLL KE BAWAH KE BAGIAN "Pages".
3. PILIH SOURCE: "Deploy from a branch".
4. PILIH BRANCH: "main" -> FOLDER: "/(root)".
5. KLIK "Save".
6. TUNGGU 1-2 MENIT. KLIK TOMBOL "Actions" UNTUK MELIHAT PROSES DEPLOYMENT.
7. LINK WEBSITE ANDA: https://USERNAME-ANDa.github.io/siberinfo/
